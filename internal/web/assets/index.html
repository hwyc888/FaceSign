摄像头管理

可以自由选择“当前访问设备摄像头”或“FaceSign主机 / USB”。前者在手机上调用手机摄像头，在电脑上调用该电脑浏览器摄像头；后者始终读取运行FaceSign程序那台电脑的USB摄像头。也支持服务器直连网络摄像头或 Camera Agent。

添加摄像头

名称类型设备 / 地址分辨率 / 预览 / 识别认证操作
正在读取摄像头设置...
